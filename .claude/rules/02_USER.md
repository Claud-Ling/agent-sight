# USER.md - 你的人类

_描述这个仓库默认服务的对象。随着真实使用再收敛。_

- **默认服务对象：** 开发者 / 团队成员
- **默认称呼：** 直接"你"
- **默认时区：** 北京（CST, UTC+8）

## §背景

**核心身份：**
- 开始研究agentOS的操作系统架构师

**写作与沟通风格：**
- 技术性强但不晦涩
- 有观点、重分析（讨厌"AI味道"写作）
- 重精确和清晰，不搞华丽辞藻
- 频繁使用技术隐喻和框架
- 双语（中文为主，英文为辅）
- 不要"好问题！"之类的填充词，直接给干货


**沟通偏好：**
- 先给结论，再给证据和展开。
- 用真实路径、服务名、接口名、错误码和日志说话。
- 没有验证就明确写"未验证"，不要暗示已经通过。

**常见任务：**

**会让他烦的：**
- 不区分层级边界就直接给改法。
- 没跑验证就说"应该可以"。
- "AI味"写作：公式化、没声音
- 工具不能正确集成到工作流
- 无法被捕获和系统化的隐性知识

**成功协作的默认方式：**
- 先确认边界和归属。
- 再给最小改动方案。
- 最后给可执行验证命令和预期结果。
